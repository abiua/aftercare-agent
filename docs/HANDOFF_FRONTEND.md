# D · 售后工作台与测试中台

## 启动

`cd frontend && npm ci` 安装锁定依赖。当前本地检查使用 Node 24。

| 环境 | 命令 | 页面 | 同源 API 转发 |
| --- | --- | --- | --- |
| 体验 | `npm run dev` | http://127.0.0.1:5186 | 8020 |
| 隔离测试 | `npm run dev:test` | http://127.0.0.1:5187 | 8022 |

`npm run build` 生成 `frontend/dist/`，正式反向代理同源转发 `/api`，事件流要允许即时转发。体验和测试分别启动对应的后端。登录填入由对应环境发放的凭据。前端不内置任何角色凭据。

## 页面与业务链

- 登录经 `GET /api/me` 核对角色，访问凭据保存在当前标签页会话中。退出清除凭据和工单定位。工单链接携带工单编号，页面刷新后重新核对身份、读取原工单。
- 客户与客服创建工单，使用订单版本。其余业务操作使用提交前确认的案件版本。冲突时读取最新快照并保留清楚的提示。相同表单在不确定的网络结果下重试时，沿用请求编号。
- 照片通过多段表单提交，预览经鉴权读取私有字节并在页面撤销临时地址。当前与历史材料审核分开显示。客服可登记取消履约、逐商品退件与验货事实，审批人可核对部分退款处置。
- 客服与测试员可发起助手运行，选择单 Agent／三 Agent 和模型策略。轨迹区分协调、查证、核验、工具、模型调用和冲突处理。等待材料和等待材料审核使用不同提示。客服补齐条件后明确继续同一运行。草案携带事实版本，可由客服带入编辑并提交，后端重新验证后才建立审批对象。
- 方案审批、重新审批、模拟执行和结果核对各有独立入口。执行使用当前有效的审批。结果未知时从原记录核对，未知金额继续由业务账本处理。退款进度查询区展示已登记的金额或回执。
- 业务事件与运行事件通过带 Bearer 的只读 SSE 请求拉取。重连携带最后接收序号并过滤重复。运行有已暂停或结束信号时读取最终快照。主动刷新和断线恢复均为读取操作。
- 测试人员有独立的测试中台，提供用例筛选、冻结输入和预期、实验启动与取消、预算与进度、指标与分母、案例复核历史、发布门槛、成对比较和 JSON/CSV 下载。来源按受控测试、真实模型、故障注入、压力测试分别标记。能否启动及评测数值以评测 API 返回为准。

## 根集成检查路径

1. 客户创建破损工单。客服从「助手协作」启动三 Agent，记录运行与线程编号。
2. 观察待补图状态，上传商品和外包裹照片。从原运行继续，观察待审核。客服查看私有照片并保存审核，再次继续。页面刷新前后核对同一工单、运行、线程和历史事件。
3. 客服提交合法处理方案。审批人批准，客服模拟执行并查看回执。更换材料版本或使用过期审批时核对页面提示及 API 拒绝；用客户凭据核对跨账号不可见。
4. 测试人员进入测试中台，选择隔离数据版本和少量案例启动受控实验。核对实际与预期、证据、分母、待复核和发布门槛，确认导出数据与界面一致。启动第二次同案例实验后检查成对差异。

## D 侧证据

`npm test` 的三个纯前端协议测试覆盖中文分块、CRLF、多行数据、空闲事件与断流残片。类型检查、代码检查和生产构建通过。Vite 报告主要界面包超过 500 kB。首轮类型检查发现事件流类型和方案分支联合类型错误，已修复。ESLint 9.39.5 的 Minimatch 兼容错误通过升级到支持当前工具链的 ESLint 10 解决。

D 验证范围为前端协议、静态和构建。正式浏览器、真实 API、PostgreSQL、私有对象存储、进程重启与模型评测证据由根集成另记。

## 评测页面补齐

- 单案默认显示预期步骤、实际动作、关键检查、模型调用与估算费用，以及已核验的引用。原始状态码、工具轨迹和 JSON 置于展开证据中。费用审计不全或任一调用缺费用时显示未知。
- `GET /api/evaluation/capabilities` 的 `eval_import`、`eval_retry`、`eval_gates` 明确开放对应操作。兼容回退使用运行信息的同名布尔值。缺少支持时页面保留可读记录并提示对应入口不可用。
- 导入原始 UTF-8 JSON 并提交 SHA-256 校验值和来源；记录单列为待核验。重跑基于已结束的原结果建立关联实验，保留旧记录，真实来源会提示费用。技术门槛按已选阈值及检查依据展示，独立审批状态单列。
- 对照 URL 可直接还原两组实验和案例重复编号。对照表提供双方详情入口、差异筛选和可复制的成对链接。
- 协作轨迹接收临时草稿片段。重连回放按事件编号去重。收到草稿丢弃、提交或运行结束信号时撤下预览。业务方案仍读取正式运行快照。

干净 macOS 临时目录通过 lint、类型、生产构建和 10 项前端测试。前端候选镜像为 `aftercare-frontend:evaluation-ui`，与既有部署标签分开。导入、重跑、阈值和真实流式预览待后端合并后的浏览器验收。
