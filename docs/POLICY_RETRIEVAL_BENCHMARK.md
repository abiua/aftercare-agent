# 政策检索开发基线

[历史混合检索报告](../reports/hybrid-pg.json)记录了真实 PostgreSQL 中 14 条政策向量、512 维 BGE 编码及一次查询的三份排序。它验证检索路径，报告没有固定查询集、参考条款或 Recall。

[查询集 v1](../data/retrieval/queries.v1.json)固定 14 条中文表达、案件意图、商品、时间以及期望条款 ID 和版本。13 条有检索参考，另有一条同优先级版本冲突只评适用性。覆盖货损、错发、退款进度、否定表达、同义改写、多条款，以及未来、草案和商品范围版本。期望条款由开发者按模拟店铺规则给出，属于开发诊断，独立人工金标与质量验收待完成。合成版本仅用于本查询集。

## 三条排名

每条查询先使用与业务相同的政策版本解析器确定候选。脚本使用已知案件意图和生产检索词前缀构造查询。三种排序共享完全相同的查询文本和候选条款。

| 方法 | 独立排名来源 |
| --- | --- |
| BM25 | `PolicySearch.search_selected().lexical_versions`。jieba 分词，按 BM25 排序，零匹配条款不补齐。 |
| Semantic | `PolicySearch.search_selected().semantic_versions`。锁定本地 BGE 快照，带生产查询前缀编码，使用真实 pgvector 余弦距离排序。 |
| RRF | `PolicySearch.search_selected().documents`。以上两种完整排序经过生产 RRF 融合后取前 k。 |

按 `(条款 ID, 版本)` 匹配。对每条查询以取回的期望条款数除以该查询的全部期望条款数。分别计算 Recall@1、@3、@5，各方法使用相同的 13 条配对查询，等权宏平均，并按意图拆分。报告保留三条原始排名、候选、阻断原因与配对平均差。发生版本冲突的查询不进入 Recall 分母，仅验证冲突版本排除及阻断码。发现候选向量缺失时运行报错，以免把降级的 BM25 写作混合结果。该测量位于检索层，图在检索后补齐必要条款的行为、引用支持及意图分类需各自评测。

## 实际结果

真实 test PostgreSQL 和本地 BGE 完成了 15 个条款版本的隔离索引。13 条正向查询均获得三种排名，另有 1 条冲突检查。下表为逐查询等权宏平均。[原始报告](../reports/policy-retrieval-dev-v1.json)

| 截点 | BM25 | BGE Semantic | RRF | RRF 相对 Semantic |
| --- | ---: | ---: | ---: | ---: |
| Recall@1 | 50.00% | 61.54% | 65.38% | +3.85 个百分点 |
| Recall@3 | 88.46% | 96.15% | 92.31% | −3.85 个百分点 |
| Recall@5 | 92.31% | 100.00% | 92.31% | −7.69 个百分点 |

- `D03` 否定错发、询问货损补证。RRF 将 `POL06` 从语义排名第 2 提到第 1。`D04` 同时询问货损补证及退款处置，RRF 第 1 为非期望的 `POL09`，第 2 和第 3 才覆盖两条期望。相反，语义排名第 1 即为期望条款之一。
- `R01` 查询已有退款进度。期望条款 `POL08` 在 BM25 排第 11、语义排第 3，RRF 前 5 未取回。`R03` 涉及旧请求和超时核对，语义排名在前 3 只取回 `POL12`，到第 4 才取回 `POL08`，RRF 前 3 覆盖两条。这两例保留了退款场景的反向变化。
- `W04` 返回 `CONFLICTING_POLICY_PRIORITY:POL13:P001`，三个排名均未纳入该条款。未来版、草案及另一商品的专属版本均按查询范围排除。

RRF 在本开发集的第一位取回表现领先，语义检索在前三和前五领先。该结果限于 13 条开发者规则期望查询，保留各方法的未命中记录。生产参数和选型保持原配置，正式选择仍需独立验证集与人工复核。

## 运行

在已初始化向量扩展的隔离 test PostgreSQL 环境运行，脚本严格校验 test 数据库目标。只在随机命名空间建立检索向量表，结束时删除本次命名空间。BGE 从本地目录加载，不发送付费模型请求。首先可检查查询集和适用范围，不连接数据库。

```sh
cd backend
uv run --frozen python ../scripts/benchmark_policy_retrieval.py --validate-only
uv run --frozen python ../scripts/benchmark_policy_retrieval.py \
  --output ../reports/policy-retrieval-dev-v1.json
```

默认本地模型目录为 `models/7999e1d3359715c523056ef9478215996d62a620`，可用 `--model-dir` 指定同 revision 的本地目录。报告记录查询集、业务基线和模型文件摘要。输出使用新路径，已有报告保留。
