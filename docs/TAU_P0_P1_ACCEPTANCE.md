## 验收边界

这是离线数据接入验收，不是 Agent 任务成功率验收。状态探针不执行上游换货，不结算，不是官方评测。尚未实现上游完整身份核验工具、可写业务工具适配、模拟客户多轮执行、官方评分，也未注册到现有聊天服务。文件分区不是操作系统沙箱，后续模型只应获得受限工具，不应获得本地文件系统或构造工具身份的能力。

本次无模型调用、无支付、未启动 Colima；无旧 PostgreSQL/S3 一致备份，相关备份与恢复验收须在首次修改旧存储前完成。此前图库、模拟退款和历史评测保持，不被 τ-bench 覆盖。
