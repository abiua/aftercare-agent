# P5 普通案例真实文本三臂试运行

范围：DAMAGE-ORDINARY 开发合成案例，复用已核验5200专属test源；strong_single、single_staged、multi，固定同一scope/政策目录/消息/原图记录，固定gpt-6.1-terra，输出1800，上下文登记32000。文本输入不含原图像素，不构成新视觉验收或正式留出评测。

每臂最多8次请求和0.40美元保守预留，总最多24次及1.20美元。按本机已登记费率向上取整预留，预检重新核对；实际账单未知，报告估算与预留分列。未知发送占用预算且同一请求不得重发，空余额度不跨臂挪用。

旧API/worker保持离线，仅专属验证器读取本地临时密钥副本。先绑定固定镜像、完整计划SHA、物理PG身份/S3标记、冻结scope与逐臂标识，再允许访问指定Responses URL；关闭SDK重试/重定向、stream及图片传输。网络本身不是通用URL防火墙，门禁只声明受审SDK路径。无真实支付、无自动审批。正常结束移除验证器及本地密钥副本；主机异常退出必须先核对journal与所有权清理，不能从头重跑。

报告分别列执行环境验证、供应方传输、每阶段工作流完成、候选可用及程序规则。顶层通过必须三臂每一必需阶段的最终尝试成功、有原生最终结果事件、可比输入与合法业务终态、候选可用，且wire HTTP/数量与账本使用量费用已知。HTTP200不等于业务正确；缺候选、401、未知响应、技术失败转人工均保留原记录并标失败/部分。wire只绑定实验行，不声称匹配到逐次逻辑尝试。无独立人工标签，业务决策质量保持未测。

实际执行须先记录只读预检生成的完整计划SHA，使用独占新报告与新私有目录。每行原生P3、原始输入和检查点保留；不改写控制报告、历史负时延、原盲审或备份。后续复杂案及消融另开明确计划与预算。
