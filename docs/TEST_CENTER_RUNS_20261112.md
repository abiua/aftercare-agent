# 测试中台：运行、记录与对比

## 本次交付

1. 新增“工单测试记录”：从数据库读取实际调查，支持按订单查询、分页、筛选调用失败/缺方案、同工单版本并排阅读、调用耗时与错误、费用明细、对比JSON导出。14条既有调查已可读取；不导入报告伪装成实际运行。
2. 新增“运行单／多Agent对比”：指定同一组案例、同一模型策略、重复次数及每组预算，建立两个独立实验，复用现有幂等创建、隔离执行与成对比较。第二组提交失败可继续，第一组保留。
3. 对比页默认显示主要指标，提供完整指标展开、改善/退步/待人工评测数量。没有审核标签的指标仍为未知；“已通过案例占已运行案例”不叫决策正确率。
4. P5独立环境接入离线评测执行器，实例锁与已有实验租约防重复执行。只处理离线/故障/负载任务，不加载模型。对象存储严格绑定P5本机18340与专用bucket，案例继续使用独立命名空间。

## 指标与审核

- 业务：动作、金额、必要补证、转人工与规则检查；独立正确率需要人工标注。
- 证据：事实遗漏、政策引用、适用版本、材料归属；保留分母与待评项。
- 纠错：错误建议、被拦截与漏检、补查前后的变化；缺少反证轨迹不能填纠错成功。
- 运行：调用次数、失败/超时、耗时、估算费用、未对账预留；未知费用不归零。
- 比较：同案例配对的改善/退步，费用和延迟；普通与复杂分别看，独立审核与客服业务审批分开。

## 当前限制与下一步

当前按钮使用已有售后图（单Agent/串行多角色），不是最新聊天调查的强单Agent/单Agent三阶段/独立并行多Agent。现有三组聊天评测内核需要继续通过其冻结输入、权限与付费准入接口接入，不能用旧流程分数声称新版多Agent更好。当前环境只验证离线运行流程；真实模型按钮因API离线而禁用。

工单记录对比选项来自当前页；目前按精确订单号查询。工单建议未接入独立评分标签，正式正确率仍待人工审核。P6故障回退与生产并发能力不在本次交付范围。

## 使用

打开 http://127.0.0.1:5225/ 选择测试员，进入“工单测试记录”或点击“运行单 / 多 Agent 对比”。

P5 API/前端依照infra/TAU_P5_RUNTIME.md启动后，在项目根目录另开终端运行（Ctrl+C关闭）：

```sh
PYTHONPATH="$PWD/backend/src:$PWD:$PWD/scripts:$HOME/.cache/aftercare-agent/tau-p4-rag-deps" \
  "$HOME/.cache/aftercare-agent/tau-p4-venv/bin/python" scripts/tau_p5_evaluation_worker.py
```

历史scripts/aftercare.sh仅管理旧容器演示，尚不包含这个本机执行器。
