## 已核对的方向与机制

- 真实持久P3快照派生同事项消息、原图引用、未核实观察及业务/政策记录；模型数据范围单独登记，旧模拟案例登记不能自动发送客户聊天。
- P2静默窗口发布结果作为自动调查的发现来源，持久请求绑定实际客户、当前事项、回合与原输入。新消息使旧回合失效。已覆盖的致谢消息不启动新调查。
- 单Agent支持同轮独立工具并行和多轮取证；多Agent事实/政策首轮独立并行，核验接收实际原始工具证据。受控同步点测试观察到真实并行，不以总时长猜测。
- root发现并要求修正：图片模糊不能单独触发多Agent；软性政策适用歧义不能全部提前转人工；P4实际工具来源必须与P3候选证据锚点一致；核验不能只看到上游意见和证据编号。
- 局部补查须保留未变证据，撤销受影响主张。依赖环应拒绝；下游关键主张失效不能静默删除后宣称方案已核实。被规则阻断的原始完整候选应保留，不能靠改成笼统转人工掩盖错误金额或动作。
