# P2.1 OCR 对比与阶段验收（2026-11-12）

结论：**离线适配器、固定样本、真实模型对比和坏例分析验收通过；低质表格自动提取质量未通过。停止于 P2.1，P3 未开始。** Sol6.1 子代理完成实现，主代理审查集成；另一个子代理从原始 TSV/模型 JSON 独立重算指标。这里的复核是代理复核，不是独立真人标注。

## 实际交付

- `scripts/p21_paddle.py`：实际 PP-StructureV3 CPU 推理，接收整页图片或选定 PDF 页，保留原始模型结果、坐标、预测 HTML、单元格跨度及来源哈希；多表不按答案择优，无效结构保留错误。依赖隔离在 `.runtime/p21-paddle`。
- `scripts/build_tau_ocr_fixtures.py` 与 `data/tau-ocr/`：两张合成中文源页，各派生清晰/低质扫描，共四张 OCR 输入。表格包含多层表头、横向合并与纵向合并；低质叠加降分辨率、倾斜、模糊、噪声和压缩。参考与退化参数先冻结，主代理视觉检查四图。
- `scripts/evaluate_tau_ocr.py`：同输入比较英文历史语言设置、中文 Tesseract 与 Paddle；失败保留分母，关键文本和单元格归属分开评分。
- [复现方法](TAU_P21_PADDLE.md)、[评分协议](TAU_P21_EVALUATION.md)、[坏例分析](TAU_P21_BAD_CASES.md)。原始结果在 `reports/tau-p21/`，正式比较 `comparison.json`，缓存后串行复跑 `comparison-cached.json`。

Paddle 是新增离线候选解析路径，尚未替换 `tau_documents.py` 默认引擎，也未接入在线工单或 RAG 入库。原生 PDF 继续保留原解析路径。OCR 输出始终是提取观察，不等于审核事实。

## 同输入实测

CER 为去空白后字符编辑数/参考字符数，越低越好；保留标点、数字、小数点和否定。阅读顺序差异也会计错。

| 指标 | Tesseract 英文参照 | Tesseract 中英基线 | PaddleOCR |
| --- | ---: | ---: | ---: |
| 总体 CER | 596/644 = 92.55% | 87/644 = 13.51% | 59/644 = 9.16% |
| 清晰政策 CER | 95.63% | 17.50% | 0.63% |
| 低质政策 CER | 92.50% | 13.75% | 0.00% |
| 清晰表格正文 CER | 91.36% | 11.11% | 9.88% |
| 低质表格正文 CER | 90.74% | 11.73% | 25.93% |
| 金额片段保留 | 0/8 | 8/8 | 8/8 |
| 否定片段保留 | 0/6 | 5/6 | 6/6 |
| 日期/期限片段保留 | 0/12 | 12/12 | 11/12 |
| 例外片段保留 | 0/4 | 3/4 | 4/4 |
| 清晰表格位置+跨度+文字匹配 | 不提供结构 | 不提供结构 | 16/16 |
| 低质表格位置+跨度+文字匹配 | 不提供结构 | 不提供结构 | 2/16 |

Paddle 相比中英基线总体 CER 降低 4.35 个百分点，但低质表格更差。两张表的合并跨度均为 4/4，仍无法保证文字归属正确。金额片段命中不代表金额与业务条件绑定正确。Tesseract TSV 提供坐标，但本路径不提供表格结构，不能把“不支持”计成结构错误率100%。英文设置是语言不匹配参照，不作为 Paddle 优势的公平基线。

## 运行与保护核验

本机 macOS arm64 CPU，PaddlePaddle 3.2.0 / PaddleOCR 3.3.1 / PaddleX 3.3.10，四线程。正式首次运行仍有懒加载权重下载，单页时间不能用于公平延迟比较。

缓存后另做串行复跑：Paddle 初始化约9.88秒，四页分别3.20/2.13/5.04/3.76秒；中文 Tesseract 四页约0.37/0.33/0.38/0.36秒，英文约0.20/0.17/0.20/0.18秒。Tesseract 每页含进程启动，Paddle为同进程；这是单轮观察，不是并发/P95/生产性能测试。缓存复跑原始识别正文和表格与首轮一致。离线本地推理未调用付费模型 API。

主代理执行 P1/P2/评分器/适配器联合回归27项通过，Ruff检查通过。真实扫描PDF第1页成功生成单表；详见 `reports/tau-p21-acceptance-20261112.json` 机器验收记录。572份原有数据、历史报告、P1/P2源码及测试文件逐项哈希一致；新增依赖与权重独立保存。未启动原应用、数据库或 Colima。

## 通过范围与遗留项

通过的是可复现对比能力及风险识别，不是全部 OCR 样本识别正确。合成参考由 Agent 编写，两张源页的清晰/退化版本相关，不能当四个独立业务样本或企业总体准确率。尚未覆盖真实中文店铺扫描、手写、多栏跨页无框表格和多种拍摄设备。

低质表格目前不得作为自动政策入库的可靠来源。后续可比较倾斜校正、文字坐标与表格单元匹配、更强表格模型；必须保留本轮原始结果，增加独立样本后再选默认方案。尚未实现通用的在线错位检测门禁，不能声称模型已经能自行发现所有错位。本轮不据参考答案纠正输出、不启动 P3。
