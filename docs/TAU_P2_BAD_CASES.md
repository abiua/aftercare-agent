# P2 文档解析 bad case

2026-11-12。本报告来自实际本机提取与代码审查；样本为项目自编格式测试文档，不是企业生产数据，也不是独立真人标注集。未测中文扫描件、复杂合并单元格、手写内容或大规模语料。

## OCR-001：字形混淆，尚未自动纠正

- 输入：`data/tau-documents/synthetic_policy_scan.pdf` 第 1 页，原图写 `R-17: Issue a credit only if the seal is intact.`。
- 实际 OCR：`R-17: lssue a credit only if the seal is intact.`，把大写 I 识别成小写 l。
- 原始证据：`.runtime/tau-p2-independent-ocr.Wg2xCg/scan/document.json`、`scan/original/` 和 `run.log`。原始记录保留，不回填标准答案。
- 工具：pdfplumber 0.11.9、Poppler 26.05.0、Tesseract 5.5.3，eng、300 dpi；该行最低词置信度 79.351486。置信度不是业务正确率。
- 影响：文字未逐字无误；不能把 OCR 当作人工核实政策。主代理视觉核对原生/扫描共四页，原图中的条件、否定、例外和金额清晰。
- 处置：保留原图、页码/坐标和原始识别文本，标记 `needs_review`。不使用针对测试答案的文字替换，不宣称 OCR 已修好。
- 状态：已暴露并标记风险；自动纠正待后续有代表性的 OCR 样本评测。

## STRUCTURE-001：扫描表格不能仅靠文字恢复对应关系

扫描件识别出的商品名和金额不等同于可靠的行列关系。当前 OCR 输出保留文字及坐标，不伪造结构化表格；扫描页整体提示文字与表格结构需复核。原生 PDF 的显式表格由布局解析器提取，另行核对单元格。两类结果不得混用为“表格解析均通过”。

## EMPTY-001：空白与提取失败必须明确区分

初版把空白/OCR失败与正常 OCR 都标为 `needs_review`，命令也可能成功退出，存在下游误用空政策的风险。审查要求另设 `extraction_status`：完整提取、空结果、部分提取分别记录；空或部分结果返回非零，保留诊断；损坏 PDF 明确拒绝。最终回归结果见阶段验收报告。

## EXPORT-001：导出半成品

初版先创建目标目录再逐个写入，观察者可能看到不完整导出。审查要求先在同父目录临时构建原件、结构化结果与预览，再受锁保护发布；已有输出不能覆盖。此为工程故障案例，不是模型正确率样本。最终回归结果见阶段验收报告。
